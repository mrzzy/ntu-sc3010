# SC3010 Case Study Assessment

## Project (20%)

- Groups of 4 students. Each group conducts 2 in-depth case studies about cyber security.
- The project will be either submission of video presentation, or live presentation on week 13, determined by the lecturers later.
- For each group, video: 10 min; live: 8 min presentation + 2 min QA.
- All members must do the presentation & understand BOTH case studies.
- Random group allocation. Allocation results will be released by Week 3.

## Judge Criterion

- **Topic selection**: real-world security incidents, better to have significant impacts. They should be related to the content discussed in this course.
- **Technical depth**: describe the technical details about the mechanism of the incidents. It is recommended to perform code analysis for the vulnerabilities. Having demos will be a plus.
- **Presentation quality**: clear presentation and organization.
