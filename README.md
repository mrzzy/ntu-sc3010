# SC3010 Project: OpenAI-Hugging Face incident

## Overview

The OpenAI–Hugging Face incident involved an AI agent led cyberattack against Hugging Face infrastructure.

Our project reproduces and demonstrates several of the security issues associated with the incident, as controlled proof-of-concepts.

# Contents

- **[Unsandboxed HDF5 Dataset](./hdf5-pwn)** demonstrates how an unsandboxed HDF5 dataset can become an attack surface when it is loaded or processed without appropriate isolation and validation.
